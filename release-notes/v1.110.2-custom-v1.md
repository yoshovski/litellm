# LiteLLM v1.110.2-custom-v1

Custom LiteLLM build based on upstream `v1.110.2` for Linux amd64.

### Fork behavior

The release carries forward dashboard branding, branded SMTP notifications, the organization creation fix, and the fork’s Enterprise default. Auto Router is available without per-capability count limits. Key rotation and team key counts use the upstream implementations.

### Upstream fixes

The upstream patch fixes duplicate events and fallback restarts in streamed Responses API calls, GPT-6.2 prompt caching in Chat Completions and Messages, and memory retained after completed requests. See the upstream release for the full list.

### Upgrade verification

An isolated PostgreSQL upgrade from LiteLLM `1.87.1` preserved a YAML model alias, a database model name, a team alias, and a virtual-key alias, all exercised with the same existing key. The release image passed certificate trust, PostgreSQL startup, the Enterprise default, and routed completions through two Auto Routers using the same classifier. Back up PostgreSQL and the mounted config before running the migration job, and keep schema updates disabled on serving instances.
